# 沟通实验室 · Communication Lab

用科学严谨的态度，结合公开实证文献、数学验证与 AI Agent，系统探索和分享人类沟通的底层逻辑。

Exploring the underlying mechanisms of human communication through empirical literature, verifiable models, and open public specifications.
